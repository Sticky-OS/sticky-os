How to install custom firmware on the reTerminal Sticky

{{NAME}} replaces the firmware the reTerminal Sticky shipped with. You flash it once over a USB cable, which takes 3 to 4 minutes; after that it updates itself over WiFi. Here is every step, from a copy of the original firmware to going back.

What you need

  • A Seeed reTerminal Sticky. {{NAME}} runs on this board only, the 3.97-inch 800 x 480 one with an ESP32-S3, not on Seeed’s larger reTerminal E1001 or E1002.
  • A USB-C cable that carries data. Some cables only charge; if the computer doesn’t see the board, try another.
  • A computer with either esptool (it needs Python 3) or Chrome or Edge, for Espressif’s ESP Tool in the browser.
  • sticky-os-full.bin and sticky-os-full.bin.sha256 from the latest release on GitHub.

Install esptool with pip install esptool on macOS and Linux, or py -m pip install esptool on Windows.

One rule: 115200 baud

The board’s USB-serial chip is only reliable at 115200 baud. Faster speeds, such as 460800 or 921600, fail part way through. Every command below says --baud 115200, and ESP Tool needs the same setting. At that speed, 1 MB takes about 97 seconds.

Before you flash: a backup, if you want one

You don’t need a backup to go back. Seeed’s official web flasher puts the original firmware (v1.2.0) back at any time, from Chrome or Edge over USB. A backup of your own board is only worth it if you want to keep its exact state, such as its pairing with Seeed’s app.

A backup reads the whole 32 MB flash, so it takes about 50 minutes. It holds your WiFi password and the device’s cloud tokens, so keep the file private. On macOS or Linux:

esptool --chip esp32s3 --baud 115200 read-flash 0 0x2000000 factory-32mb.bin

On Windows (the port is the board’s COM port in Device Manager):

py -m esptool --chip esp32s3 --port COM5 --baud 115200 read-flash 0 0x2000000 factory-32mb.bin

The file should be exactly 33,554,432 bytes. If it stops part way, run it again.

Flash {{NAME}} with esptool

Plug the board in. First check the download, then write it at address 0x0. The file is about 4 MB, so this takes about 3 to 4 minutes. On macOS or Linux:

shasum -a 256 -c sticky-os-full.bin.sha256      # should say OK
esptool --chip esp32s3 --baud 115200 write-flash 0x0 sticky-os-full.bin

On Windows, compare the hash by eye with the .sha256 file, then flash:

certutil -hashfile sticky-os-full.bin SHA256
py -m esptool --chip esp32s3 --port COM5 --baud 115200 write-flash 0x0 sticky-os-full.bin

esptool puts the board in download mode by itself through the USB-C port, and on macOS and Linux it finds the port by itself too. If you have several, add --port /dev/ttyACM0 (or /dev/cu.usbmodem…).

Or in the browser, with ESP Tool

Espressif’s ESP Tool runs in Chrome or Edge on a computer, with nothing to install. Set the baud rate to 115200 before Connect, pick the board’s port, set the flash address to 0x0, choose sticky-os-full.bin, then Program.

The first start and the setup app

When the flash is done the board restarts into {{NAME}}. The first start shows a welcome screen with the setup app’s address and a QR code of it. The apps work without WiFi too, so you can tap Start and look around first.

Then open the setup app in Chrome or Edge on a computer (Chrome on Android for Bluetooth) and connect over USB, or over Bluetooth: on the board, Settings → Connect to the setup app, and type the 6-digit code it shows. The setup app runs in your browser and sends nothing anywhere but to your board. In it you add your WiFi, the town for the weather if the board can’t find it, and if you like up to three calendar links and an OpenAI key for voice notes and recipes. Passwords and keys can be written but never read back. There is a demo if you want to see it before you start.

If it can’t connect or stops part way

  • Check that you used --baud 115200. A faster speed is the most common reason a flash fails part way.
  • Try another cable, or another USB port.
  • Close any other program that has the port open: a serial monitor, the setup app, or a browser tab with ESP Tool.
  • On Linux, add yourself to the dialout group.
  • If a backup stops part way, run it again; the finished file must be exactly 33,554,432 bytes.

After that, updates come over WiFi

You only use the cable once. Settings → Software update checks the project’s GitHub releases once a day, and when you tap Check now. Install puts a new version on, checks it, and restarts. If a new version doesn’t start properly, the board goes back to the one before. Installing by itself is off by default, because releases aren’t signed yet; you can turn it on in the same place.

Going back

Nothing here is permanent. Seeed’s web flasher puts the original firmware back, or you can write your own backup with esptool: restore the Seeedash firmware has both. If you are still choosing, the firmware comparison sets {{NAME}} beside the other options for this board.

The README has the same steps, and the questions on the home page answer the short ones.

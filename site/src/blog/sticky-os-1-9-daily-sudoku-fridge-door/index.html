{{NAME}} 1.9: a daily Sudoku for the fridge door

{{NAME}} 1.9 adds a new daily puzzle, Sudoku. It sits under Daily in the Games folder, next to Daily maths: a new puzzle every day, made on the board itself from the date, with no internet needed, and the same puzzle on every board.

A puzzle a day

The Games folder’s Daily tile now opens today’s puzzles: Daily maths, as before, and Sudoku. Each day brings a new Sudoku, at three levels: Easy, Medium and Hard. The board makes it from the date, so it needs no internet and no account, and every board running {{NAME}} has the same puzzle that day: one to compare over breakfast. The board keeps a streak of days and your best times.

Why e-paper suits it

Sudoku is a game of looking, not of speed: a grid that sits still, a number now and then. That is what e-paper does well. The puzzle stays on the screen all day without using power, sharp as print, and is there to pick up again each time you pass the fridge.

How to play

Fill the grid so that every row, every column and every 3 × 3 box holds the numbers 1 to 9 once each. Tap Daily, then Sudoku, and pick a level. Tap a cell, then a number. Pencil marks note the numbers a cell could still be, and a number that clashes with another in its row, column or box is marked. How to play the games has every step, with the board’s own screens.

Get it

{{NAME}} 1.9 is on GitHub Releases. On a board running {{NAME}}, open Settings → Software update, tap Check now, then Install. To install it the first time, see Install. Sudoku is under Daily in the Games folder.

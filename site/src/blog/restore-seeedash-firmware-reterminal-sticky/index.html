Restore the Seeedash firmware on the reTerminal Sticky

Flashing {{NAME}} replaces the firmware the reTerminal Sticky shipped with, but not for good. There are two ways back to Seeed’s stock firmware: Seeed’s official web flasher, or a backup of your own board.

What you are going back to

The board shipped with Seeed’s firmware, version 1.2.0, the one that works with the Seeedash app. (The project’s development notes call it SenseCraft firmware 1.2.0, its earlier name.) Seeed’s official firmware page calls it the Seeedash-ready firmware. Before you start, you can check what your board runs now: in {{NAME}}, Settings → About this device shows the firmware version.

Before you start

  • Use a USB-C cable that carries data, and a computer with Chrome or Edge (for the web flasher) or esptool (for a backup).
  • Close anything that has the board’s port open: the {{NAME}} setup app, a serial monitor, or a browser tab with ESP Tool. Only one program can use the port at a time.
  • Your notes, tasks, recipes, game progress and the photos you sent from the setup app live in the board’s flash, and a restore writes over it. Copy anything you want to keep first.
  • Books and photos on the microSD card are on the card, not in the flash, so flashing doesn’t touch them. {{NAME}}’s hidden .sticky/books folder stays there too; you can delete it.

Way 1: Seeed’s official web flasher

This needs no backup and nothing to install. It runs in desktop Chrome or Edge, over Web Serial.

  1. Plug the board into the computer.
  2. Open Seeed’s official firmware page.
  3. Choose the Sticky official firmware; the version list showed v1.2.0 at the time of writing.
  4. Choose Standard flash, or Erase flash + flash for a full restore, then Connect & flash and pick the board’s port.
  5. Wait for the progress to reach the end. The board restarts into Seeed’s firmware.

Seeed’s page offers the erase for a full restore. We suggest it when you leave {{NAME}}: an erased flash keeps nothing of it, neither its settings (your WiFi, keys and calendar links) nor its notes and photos. Seeed’s page doesn’t say how long a flash takes; it shows the progress as it goes.

The page also has an optional Device Log, which shows what the board prints over the cable as it starts. It is useful if something looks wrong after the flash.

Way 2: your own backup, with esptool

If you made a backup before installing, as in the install guide, you can write it back. This restores the board exactly as it was when you made the copy, including its WiFi and its pairing with Seeed’s app. The file should be 33,554,432 bytes, the whole 32 MB flash. On macOS or Linux:

esptool --chip esp32s3 --port /dev/cu.usbmodem… --baud 115200 write-flash 0 factory-32mb.bin

On Windows, with the board’s COM port from Device Manager:

py -m esptool --chip esp32s3 --port COM5 --baud 115200 write-flash 0 factory-32mb.bin

Use 115200 baud: faster speeds fail part way on the board’s USB-serial chip. Writing the full 32 MB back takes about 50 minutes, as long as the backup did. Keep the backup file private afterwards: it holds your WiFi password and the device’s cloud tokens.

If it stops part way

  • Check the baud rate: 115200, nothing faster.
  • Try another cable or another USB port.
  • Close any other program or tab with the port open, and try again.
  • On Linux, add yourself to the dialout group.

A flash that stopped part way can simply be run again, by either way above.

Coming back to {{NAME}}

You can switch as often as you like. Flash sticky-os-full.bin again as in the install guide or the short version on the home page. After an erase the board starts unconfigured, with the welcome screen and its QR code, and you set it up again in the setup app. Choosing between firmware? See the comparison. The development notes have the same steps.
